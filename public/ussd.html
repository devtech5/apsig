Accueil Centrale USSD / SMS
Simulateur de passerelle opérateur — code court *789# fictif, aucune communication réelle.
Composez *789*CODE# puis appuyez sur la touche verte.

Alerter sans smartphone ni Internet

Chaque plaque porte un code court à 5 chiffres. Depuis n'importe quel téléphone, même basique et sans crédit Internet, on compose *789*CODE# ou on envoie un SMS. La centrale reçoit une alerte avec le numéro de l'appelant, ce qui renforce sa fiabilité.

Codes des plaques de démonstration :

En production, le code court est loué auprès des opérateurs (Orange, MTN, Moov) via un agrégateur. Le point d'entrée POST /api/ussd suit le format standard des passerelles (sessionId, phoneNumber, serviceCode, text → réponse « CON » ou « END »).

Envoyez « SOS <code> <1, 2 ou 3> ». Exemple : SOS 10001 1
